# LLM 服务负载追踪

## 定义

LLM 服务负载追踪指对生产环境中 LLM 推理服务的请求流量、模型使用、用户行为等数据进行长期、系统性的记录与分析，用于理解负载演化、优化系统设计和评估性能。

## Chutes 一年期研究（2026-08-17）

- **来源**：arXiv 2608.13573（预印本）
- **内容**：基于 Chutes 平台的一年期生产 LLM 服务负载研究，对跨模型、跨用户的完整生产流量做聚合、时间、模型层和用户层分析。
- **数据**：作者称将随论文发布完整的一年 trace，供后续研究直接使用，不依赖采样或合成数据。
- **意义**：填补现有短期采样研究的空白，覆盖长尾模型，为推理系统、缓存策略、负载均衡设计提供真实负载基准。
- **待验证**：预印本，数据完整性和发布形式待确认。

## 相关研究背景

- 现有公开 LLM serving trace 多短窗口、有采样或合成，Chutes 数据提供纵向视角。
- 长尾模型与用户结构对缓存、调度设计有重要影响。

## 推断

- 完整生产 trace 的开放将改善推理系统设计与基准测试的真实性。
- 负载演化分析有助于理解用户-模型交互如何塑造流量。
