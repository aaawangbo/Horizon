# 知识复利

## 定义

知识复利是指一次阅读、核验和综合的成果被结构化保存，并在后续研究、比较和创作中反复复用，同时被新证据持续修正。

## 形成条件

1. 来源可追溯，避免结论脱离证据。
2. 页面之间有明确连接，避免知识成为孤岛。
3. 新信息更新旧结论，而不是只增加新摘要。
4. 查询和创作产生的新洞见重新进入知识库。
5. 定期发现矛盾、过期内容和知识缺口。

## 对 AI 博主的价值

- 同一份资料可转化为快讯、长文、视频和对比图。
- 长期追踪一个模型或公司时，不必每次从零研究。
- 能区分短期热度与长期趋势，形成个人观点和内容壁垒。
- 发布后的数据也可回流，帮助系统学习哪些表达真正服务受众。

## 风险

错误也可能产生“负复利”。因此自动综合必须保留来源、置信度和 Git 版本历史。
