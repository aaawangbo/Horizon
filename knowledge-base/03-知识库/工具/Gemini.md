# Gemini

## 概述

Gemini 是 Google DeepMind 推出的大语言模型系列，涵盖不同规模与定位的模型变体。

## Gemini 3.7 Flash（2026-08-13 发布）

- **定位**：Flash 系列最新模型，重点改进核心推理算法，而非全新架构。
- **定价**：首发促销价约 $0.75/1M 输入 token，促销持续到 2026-12-31，之后翻倍。
- **官方宣称**：在业务工作流自动化上超越 Claude Sonnet 5 和 GPT-5.6 Terra，但需独立验证。
- **社区实测**：图像转 HTML 任务表现不错，但 Opus 5 仍领先；有开发者认为 Luna/Terra 更便宜或性能更高，削弱 Flash 吸引力。
- **注意**：官方条目仅给出发布信息和 API 文档链接，具体能力细节和基准表现待补充。
