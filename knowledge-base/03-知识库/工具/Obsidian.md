# Obsidian

## 在本系统中的定位

Obsidian 是知识库的人类界面：用于浏览 Markdown、查看反向链接、搜索、阅读关系图和人工修订。知识的真实载体仍是普通文件，因此可以用 Git 保存历史，也可以由 Codex 和自动脚本维护。

## 推荐用法

- 从 [[首页]] 和 [[知识地图]] 导航，不依赖文件夹记忆。
- 用反向链接查看一个主题被哪些页面引用。
- 用关系图发现知识中心和孤立页面。
- 新资料先放收件箱，不直接塞进知识页。
- 附件统一放入 `02-原始资料/assets`。
