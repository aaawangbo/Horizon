# 内容生产流程

## 1. 选择角度

从 [[选题池]] 或自动选题中选择一项。先回答：受众看完能多知道什么、会做什么？如果答案只是“知道有这条新闻”，继续寻找解释层和行动层。

## 2. 建证据包

- 打开关联知识页。
- 顺着 `sources` 回到来源记录和原始链接。
- 对价格、性能、发布日期、人物身份等时效信息重新核验。
- 至少区分事实、推断和个人观点。

## 3. 选择内容结构

- 快讯：发生了什么 → 为什么重要 → 谁会受影响 → 原始链接
- 解读：背景 → 新变化 → 与旧方案比较 → 判断 → 风险
- 教程：目标 → 环境 → 步骤 → 验证 → 常见问题
- 口播：钩子 → 冲突/反常识 → 三个信息点 → 结论与行动

## 4. 生成与编辑

让 AI 先写结构和事实表，再生成正文。删除空话、重复结论和没有证据的夸张表达。保留自己的判断，不把所有内容写成中性摘要。

## 5. 发布前核查

- [ ] 标题没有超出证据范围
- [ ] 时间、数字、模型名、公司名准确
- [ ] 每个关键事实都有来源
- [ ] 推断和观点有明确措辞
- [ ] 原始内容没有被大段复制
- [ ] 链接可以打开
- [ ] 内容适配目标平台和受众

## 6. 发布后回流

记录发布日期、平台、链接、曝光、阅读/播放、完播、收藏、评论、关注和转化。将表现与选题评分对比，提炼受众偏好，但不要因单篇数据过度调整长期方向。
