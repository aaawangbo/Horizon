# 使用说明

## 在 Obsidian 打开

1. 启动 Obsidian。
2. 点击“打开本地仓库”。
3. 选择仓库里的 `knowledge-base` 文件夹。
4. 打开 [[首页]]。

`.obsidian` 已配置好附件目录、模板目录、反向链接和关系图谱等核心功能。

## 你每天只需要做什么

1. 打开 [[选题池]] 或 `04-内容工厂/自动选题`。
2. 选择一个与你的账号定位匹配的角度。
3. 让 Codex 根据知识页和原始来源生成草稿。
4. 核对原文、数字和发布日期。
5. 发布后把成稿移动到 `04-内容工厂/已发布`，补充平台、链接和表现数据。

## 常用指令

### 录入单篇文章

```text
把这个链接录入知识库。保留来源，更新相关概念、人物和工具页，发现冲突时不要覆盖旧说法，并生成 3 个选题。
```

### 做一个主题研究

```text
基于知识库梳理 Agent 最近 30 天的变化。区分事实、推断和观点，列出证据不足的地方，并把有长期价值的结论写回知识库。
```

### 生成内容

```text
从选题池选择“____”，生成一篇适合公众号的文章。先读取相关知识页和原始来源，附事实核查表，不要编造数据。
```

### 健康检查

```text
按 AGENTS.md 对知识库执行 lint：检查断链、孤立页、矛盾、过期结论和缺失来源，机械问题直接修复，规则变更只写提案。
```

## 自动迭代不等于自动发布

系统会自动采集、归纳、连接和产生选题，但不会自动向公众号、小红书或视频平台发布。自动摘要可能存在理解偏差，正式发布前必须打开原始链接核验。
