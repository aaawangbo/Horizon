Motif 3 是一篇新发布的 arXiv 技术报告（arXiv:2608.09119v1），介绍了一个 decoder-only 的混合专家（MoE）语言模型：总参数量 314B，每个 token 激活 13.2B 参数；每层稀疏 MoE 有 384 个路由专家，每次选取 8 个专家。模型采用 Grouped Differential Latent Attention（GDLA）架构，并结合多 token 预测、专家特定 PolyNorm 激活与流形约束超连接。预训练约 12.5 万亿 token，覆盖网页、STEM、代码、数学、多语言等领域，训练上下文最长 256K。后训练融合通用 SFT、6 个强化学习训练的专家教师以及 1 个软件工程 SFT 教师，并通过多教师在线策略蒸馏合并能力。报告称其在推理、代码、长上下文和智能体任务上达到领先开源模型水平，但这是预印本，且 arXiv 编号日期为未来，基准表现需独立验证。

[LLM 加密推理链可被越狱提取](https://arxiv.org/abs/2608.09867) ⭐️ 9.0/10

一篇由 Jonas Geiping、Maksym Andriushchenko 等多位研究者署名的 arXiv 预印本，展示了一种针对主流闭源大模型 API 的“解密越狱”攻击。论文称，Anthropic、OpenAI 和 Google 等供应商会把模型的逐步推理（chain-of-thought）以加密文本块形式返回给客户端，且这些加密块在同一生态内的会话、用户和模型之间可以互换。攻击者由此可将某个模型的加密推理块注入同一供应商防护较弱的“兄弟模型”，迫使后者把内容原样输出为纯文本。论文还报告，通过扫描公开代码仓库中的 315,320 个推理块，恢复了 367 个个人身份信息（PII）和 182 个凭据。该论文尚未经过同行评审，且其 arXiv 编号异常，属于预印本声称，需谨慎对待。

rss · arXiv cs.AI · 8月11日 04:00

**「为什么重要」** 这一发现说明“加密推理块”并不能真正保护隐藏的思维链：供应商的防护可以通过跨模型兼容性被绕过，从而威胁到闭源模型的商业机密、用户隐私和系统安全。对依赖大模型 API 的企业和开发者而言，公开分享会话日志可能意外泄露 PII 和凭据；对 AI 安全社区而言，它揭示了一个需要在系统层面重新设计的架构漏洞。

**「可用的内容角度」** \1. 实操验证：在同一供应商的弱模型上复现“加密块注入”，看是否能真实还原隐藏推理链。2. 安全对比：比较 Anthropic、OpenAI、Google 三家 API 在防止推理链跨模型复用上的差异。3. 隐私课：以论文中的 315,320 个公开推理块为案例，提醒开发者不要公开包含加密块的会话日志，避免 PII 和凭据泄露。

**「社区讨论」** 评论区对“窃取”一词有分歧：有观点认为用户已经为 token 付费，只是无法访问隐藏内容，训练其他模型输出应当视为正常行为；也有人指出可能存在更简单的绕过方式，比如给模型一个“深度思考”工具就能触发内部思维链。还有人好奇这一兼容性是否是有意设计，并提到 API 摘要并不总是保留“先给出答案再推导”的顺序，可能掩盖模型训练数据中的记忆现象。

[RLVR+数据清洗实现人类级 Text-to-SQL](https://arxiv.org/abs/2603.20004) ⭐️ 9.0/10

rss · arXiv cs.CL · 8月11日 04:00
