## 工具

- [[DeepSeek]] — DeepSeek 是中国 AI 公司，以开源模型和低成本 API 著称。
- [[GLM]] — GLM（General Language Model）是智谱 AI（Zhipu AI）开发的大语言模型系列，涵盖 ChatGLM、GLM-4 及 GLM-5 等代际产品。该系列在国内开源生态中具有较高
- [[Gemini]] — Gemini 是 Google DeepMind 推出的大语言模型系列，涵盖不同规模与定位的模型变体。
- [[Horizon]] — Horizon 是本系统的信息雷达。它从官方博客、研究 RSS、GitHub Releases、Hacker News、Reddit 和开源趋势中抓取 AI 资讯，再调用 DeepSeek 进行筛选、
- [[MCP]] — MCP 是 Anthropic 提出的开放协议，用于标准化 AI 模型与外部工具、数据源的交互。
- [[Obsidian]] — Obsidian 是知识库的人类界面：用于浏览 Markdown、查看反向链接、搜索、阅读关系图和人工修订。知识的真实载体仍是普通文件，因此可以用 Git 保存历史，也可以由 Codex 和自动脚本维
- [[Ollama]] — Ollama 是一个开源的本地大模型运行工具，提供简洁的 CLI 和 API 来下载、管理和运行各类 LLM。用户无需复杂配置即可在本地机器上运行量化后的开源模型，是个人开发者和隐私敏感场景的常用选择
- [[Qwen]] — Qwen 是阿里巴巴通义千问团队开发的大语言模型系列，涵盖不同规模与定位的模型变体。
- [[Seedance]] — Seedance 是字节跳动推出的视频生成模型系列，最新版本为 Seedance 2.5。
- [[smevals]] — smevals 是 Simon Willison 与 Prime Radiant 合作开源的轻量 LLM 评测工具，用于对模型、提示词和 agent 框架运行小型评测并打分。
- [[vLLM]] — vLLM 是一个高吞吐量、内存高效的 LLM 推理与服务引擎，支持 200+ 模型架构，是 AI 基础设施领域的重要开源项目。
